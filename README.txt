SRI HARI HARAN RK — STUDENT PORTFOLIO
======================================

FILES
- index.html: page content
- style.css: dark modern design and responsive layout
- script.js: automatically updates the copyright year

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the portfolio in your browser.
4. To edit the page, open the files in Visual Studio Code:
   - Edit text and sections in index.html
   - Edit colors, spacing and layout in style.css
   - Edit page behavior in script.js

GITHUB PAGES (OPTIONAL)
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for the published site link to appear in Settings > Pages.

Before publishing, check that the contact information shown on the page is correct
and only publish details you are comfortable sharing publicly.
